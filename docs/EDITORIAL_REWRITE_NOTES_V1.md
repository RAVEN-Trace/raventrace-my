# Editorial Rewrite Notes V1

Evidence basis for this rewrite:

- Master Blueprint V3.0: HUMAN CLARITY CORE requires complexity to be explained in readable language without making it false.
- Reporter Domain Addendum V3.1: default reporter rhythm is Lead → Context → Evidence → Gap → Impact → Next.
- Visual Style Guide V1: public-facing material must be mobile-readable, use short leads, low text density and visible uncertainty.
- Prompt System V1.2: avoid making Raven sound like a compliance checklist; public wording should be explainable, not accusatory.

Editorial interpretation for the website:

- Protocol language remains available in metadata/audit layers.
- Public headlines and first-pass paragraphs use ordinary Malaysian Malay.
- Serious legal/process distinctions stay explicit.
- English jargon is retained only where it is a recognised term or where translation would reduce precision, with a short Malay explanation on first use.
