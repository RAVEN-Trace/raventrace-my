# Editorial Rewrite Policy V1

This branch changes public-facing wording only unless a stale status is already contradicted by a newer verified status elsewhere in the same repository. It must not invent facts, add allegations, or remove evidence caveats.

Priority order for copy:
1. Accuracy and legal/process status.
2. Public clarity.
3. Natural Malaysian Malay.
4. Readability and momentum.
5. Internal protocol terminology.

When a technical term is essential, retain it and explain it immediately in ordinary language.
